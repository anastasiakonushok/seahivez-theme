# SeaHivez — Project Overview

## Project

**SeaHivez**

## Type

Private yacht charter / yacht rental website.

## Location

Mallorca, Spain.

Primary operating area: Palma de Mallorca / S'Arenal.

## Main yacht

Numarine 55 Fly.

## Brand and design direction

The website should feel **premium**, **Mediterranean**, **modern**, **minimalistic**, and **editorial**.

## Main goals

1. Present the yacht.
2. Present yacht specifications.
3. Present rental experiences / packages.
4. Present included equipment and paid extras.
5. Show photo / video gallery.
6. Provide clear booking CTAs.
7. Integrate an external booking system later.
8. Allow important content to be editable through WordPress admin.
9. Be fast, SEO-friendly, accessible, and fully responsive.

## Initial site structure

- Home
- The Yacht
- Experiences / Services
- Extras
- Gallery
- Booking
- Contact

## Language

Initial language: **English**.

Architecture should allow multilingual support later.

## WordPress content

WordPress will manage normal Pages, Posts, and media.

## Potential future custom post types

- `rental_package`
- `extra`
- `review`
- `faq`

Potential future ACF integration should use `acf-json/`.
