# Homepage photography placeholders

SVG placeholders in this folder should be replaced with real yacht photography before production launch.

Suggested replacements:

| File | Intended content |
|------|------------------|
| `hero.svg` | Full-width hero — yacht cruising, Mallorca coastline |
| `about-yacht.svg` | Profile or three-quarter yacht exterior |
| `experience-*.svg` | Package card images (sunset, coastal, lifestyle) |
| `gallery-01.svg` … `gallery-06.svg` | Exterior, flybridge, dining, cabin, deck, lifestyle |
| `map-mallorca.svg` | Static map visual or illustration of Mallorca |

Use WordPress media library or commit optimized WebP/JPEG files here, then update paths in `inc/homepage-data.php` or future ACF fields.

Hero supports a future `<video>` background — see `template-parts/home/hero.php`.
